# Adventure

A text-based RPG written in Turbo Pascal 3.0 for various retro systems. Designed to be runable primarily on CP/M 2.2 (and CP/M+ aka CP/M 3.0).

## Systems tested

- Windows terminal (ANSI)
- Commodore 128 (ADM31)
- Amstrad CPC 6128
- Elwro 800 Junior
- BOSMAN-8

## How do I transfer a compiled file to a floppy disk image?

### Amstrad CPC

Use [CPCDiskXP](http://www.cpcmania.com/cpcdiskxp/cpcdiskxp.htm)

### Elwro 800 Junior

Use ElwroDiskManager

### ZX Spectrum +3

Use CIFE aka [CP/M Image-File Explorer](https://github.com/ProgrammingHobby/Cife) with disk profile PCW

### Commodore 128

Use [RDCBM](https://www.retroisle.com/commodore/c64128/Articles/c128_cpm.php)
